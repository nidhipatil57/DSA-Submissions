## 🌟 About This Repository

Welcome to my coding solutions repository! This repository serves as a live, automated portfolio of my competitive programming and DSA (Data Structures & Algorithms) journey. 

I previously used **NeetCode** for syncing my solutions, but I have upgraded to **[Code2Git](https://github.com/krishnasahoo11156/Code2Git)** (C2G) for a more modern, secure, and multi-platform sync experience. Every time I solve a problem and get an **Accepted** verdict, the code is immediately formatted, cataloged, and committed here in real-time.

---

## 🚀 Key Features of Code2Git (C2G)

Unlike traditional extensions, **Code2Git** operates entirely in the browser (100% client-side), meaning my credentials and tokens never touch external third-party servers.

- **Multi-Platform Support:** Automatically captures and syncs solutions from:
  - 🟡 **LeetCode** (Problems & Submissions)
  - 🔴 **Codeforces** (Contests & Problemset)
  - 🟢 **GeeksforGeeks** (Practice Portal)
  - 🌐 **HackerRank** (Challenges)
- **Automatic README Generation:** Creates rich, descriptive `README.md` files for every problem, complete with difficulty level, language, problem links, runtime, memory usage, and full descriptions.
- **Streak & Analytics Tracking:** Inside the Code2Git dashboard, I can track my active coding streak and platform metrics.
- **Leaderboard Integration:** Syncs statistics to private group/club leaderboards.
